**Notes for the reviewer (English):**

Ayant is a deals and loyalty app for venues in Bishkek, Kyrgyzstan. The UI is in Russian; English is included (Profile → Язык → English).

Two roles exist in one app:
1. User (default). Browse deals, play mini-games for bonuses, swap bonuses for venue coupons, collect points and stamps.
2. Venue (host). Profile → «Режим заведения». The scanner tab uses the camera to scan guests' QR codes; it only works for a venue owned by the signed-in business account.

Bonuses: earned only by playing the built-in free mini-games (and referrals, currently disabled). They cannot be purchased, have no cash value and cannot be exchanged for money. They are spent on coupons that venues issue (goods/services provided by the venue). There is no gambling, no real-money prizes and no in-app purchase. Apple is not a sponsor of the games or the bonus program (see https://ayant.kg/terms.html).

User-generated content (reviews, photos): users accept the Terms (https://ayant.kg/terms.html, linked on the sign-in screen) with zero tolerance for objectionable content; text is filtered before posting; every review/photo has «Пожаловаться» (report) and authors can be blocked; reports are reviewed within 24 hours.

To see the loyalty flow end to end: sign in as the venue owner on one device and open «Сканер»; on a second device (or the simulator) sign in as the user and open «Мой QR» (center tab). ⟪OWNER: add any extra step, e.g. how to get a test coupon⟫

Notifications: the onboarding explains notifications, then always shows the system dialog (no skip button). Marketing pushes (venue news) are sent only with permission and can be turned off in Profile → «Новости и акции заведений».

Account deletion: Profile → «Удалить аккаунт». Sign in with Apple accounts confirm with Apple once more; after the server deletes the account the Apple token is revoked. Venue owners' venues are unpublished.

Location is used only on the device to show distances to venues. The camera is used only by the venue-mode scanner. No tracking.

## App Privacy answers (matches SAN/PrivacyInfo.xcprivacy)

**Tracking:** No. No data is used to track users across apps or websites; no ATT prompt; no third-party ads.

Data **linked** to the user (not used for tracking):
- Contact info → Name, Email address — App Functionality (account; email verification)
- Contact info → Phone number — App Functionality (venue owners' business phone only)
- Identifiers → User ID — App Functionality
- Purchases → Purchase history — App Functionality (coupons bought with bonuses, bonus wallet ledger)
- User content → Photos or Videos, Other user content — App Functionality (review photos and text, venue content)
- Usage data → Product interaction — Analytics, App Functionality (feed impressions/taps for ranking, venue statistics)
- Usage data → Other usage data — App Functionality (games played / bonuses earned, needed for wallet limits)

Data **not linked** to the user (not used for tracking):
- Identifiers → Device ID — Analytics (Firebase Analytics app-instance ID)
- Location → Coarse location — App Functionality (distance shown on the device; coordinates are not sent to our servers — declared conservatively)
- Diagnostics → Crash data, Other diagnostic data — App Functionality, Analytics (Firebase Crashlytics)

Not collected: financial info, health & fitness, contacts, browsing history, search history (search terms are logged without user identity — ⟪OWNER: if Analytics «search» events keep the query, answer Search history → Analytics, not linked⟫), sensitive info, precise location, audio, gameplay content.

```bash
# iPhone 16 Pro Max на iOS 18.4 (на iOS 26 в симуляторе не рендерятся эмодзи)
xcrun simctl create "Ayant Shots" com.apple.CoreSimulator.SimDeviceType.iPhone-16-Pro-Max com.apple.CoreSimulator.SimRuntime.iOS-18-4

xcrun simctl install "Ayant Shots" <path-to-SAN.app>
xcrun simctl spawn "Ayant Shots" defaults write kg.san.app san.onboarded -bool YES
xcrun simctl spawn "Ayant Shots" defaults write kg.san.app san.language -string ru   # или en
xcrun simctl launch "Ayant Shots" kg.san.app -screenshots ru                          # + -screenshots-earn для экрана «Начислено»
# пройти по экранам и снять: xcrun simctl io "Ayant Shots" screenshot raw-ru/NN-name.png
python3 docs/appstore/make_screenshots.py
```

Если CDN Unsplash недоступен из симулятора, скачайте фото в папку и передайте
`-screenshots-photos <dir>` (файлы `<id>.jpg`).
